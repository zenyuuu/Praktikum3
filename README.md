# Catatan Kuliah (PHP native CRUD)

Aplikasi CRUD sederhana untuk Praktikum Komputasi Awan – Deploy Azure App Service.

- Database default: SQLite (otomatis, tanpa setup).
- Pakai MySQL: set Environment variables di App Service: `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` (opsional `DB_PORT`). Tabel dibuat otomatis.
- `index.php` berada di root repo, sesuai syarat Deployment Center.
